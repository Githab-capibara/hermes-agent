# Troubleshooting

This directory contains troubleshooting guides for common Hermes Agent
issues. Each entry follows the symptom → root cause → fix pattern.

## Conventions

- H1 headings are sentence case, starting with the doc number: `# 01. title`.
- Use [`template.md`](template.md) when writing a new troubleshooting guide.
- Link back to the relevant operations or setup doc in the Related section.
