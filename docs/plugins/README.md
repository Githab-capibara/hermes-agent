# Plugins

This directory contains plugin documentation for Hermes Agent — how plugins
are discovered, loaded, and integrated into the gateway lifecycle.

## Conventions

- H1 headings are sentence case, starting with the doc number: `# 01. title`.
- Use [`template.md`](template.md) when writing a new plugin doc.
- Plugin source lives in `plugins/`; this directory documents the contract.
