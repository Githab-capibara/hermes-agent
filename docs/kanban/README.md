# Kanban System

This directory documents the Kanban multi-agent work queue system and
multi-gateway deployment patterns. It covers board layout, workflow rules,
and how multiple gateway instances coordinate on shared work items.

## Conventions

- H1 headings are sentence case, starting with the doc number: `# 01. title`.
- Use [`template.md`](template.md) when writing a new entry.
